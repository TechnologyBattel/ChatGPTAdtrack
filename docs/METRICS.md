# Metrics dictionary

| Metric | Definition |
|---|---|
| Lead | A submitted form with a valid contact |
| Qualified lead | Status set to Qualified by a human (criteria: TODO, write yours) |
| Customer | A contact with at least one non-refunded order |
| CPL | Spend ÷ leads |
| CAC | Spend ÷ new customers |
| ROAS | Attributed revenue ÷ spend |
| Internal attribution | Last touch, 30-day window (configurable) |
| Native attribution | As reported by OpenAI, shown separately |
| Time zone | Asia/Kolkata (set in organization settings) |
| Currency | INR base; conversion rules: TODO |
