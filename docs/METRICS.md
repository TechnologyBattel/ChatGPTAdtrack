# Metrics dictionary

| Metric | Definition |
|---|---|
| Lead | A submitted form with a valid contact |
| Qualified lead | Status set to Qualified by a human. Default rule: valid contact + at least one buying-intent answer + fits the ICP; editable in settings. |
| Customer | A contact with at least one non-refunded order |
| CPL | Spend ÷ leads |
| CAC | Spend ÷ new customers |
| ROAS | Attributed revenue ÷ spend |
| Internal attribution | Last touch, 30-day window (configurable) |
| Native attribution | As reported by OpenAI, shown separately |
| Impression | One recorded ad impression (native) |
| Click | One recorded ad click (native) |
| CTR | Clicks ÷ impressions |
| CPC | Spend ÷ clicks |
| CPM | Spend ÷ impressions × 1,000 |
| Conversion rate | Conversions ÷ clicks (post-click), shown next to the view-through count |
| View-through conversions | Conversions attributed to a view, 1-day window, shown separately |
| Lead → customer rate | New customers ÷ leads in the same period |
| Payback period | Days of attributed gross margin needed to recover CAC |
| Preliminary data | Metrics for the newest 48–72 h may still settle; they are labelled, never silently final |
| Time zone | Asia/Kolkata (set in organization settings) |
| Currency | INR base. All stored amounts are integer minor units (paise); format only in the UI. |
